01 · Color system

Four-step palette

Every color has a role. Use them with intention — never swap primary for accent or dilute the system with off-palette colors.

Primary ←→ Secondary ←→ Tertiary ←→ Accent ←→
Trust Navy

Step 1 · Primary

Trust Navy

Main brand color. Used on the logo, primary buttons, navigation bars, and key structural elements. Conveys authority and reliability.

#1A3B6E — Main #12295A — Dark #0D1F45 — Deepest
Cloud Frost

Step 2 · Secondary

Cloud Frost

Supporting color for backgrounds, card surfaces, input fields, and data panels. Creates calm, airy spaces without visual noise.

#F0F4FB — Light #D8E2F5 — Mid #BFD0EE — Deep
Ink Slate

Step 3 · Tertiary

Ink Slate

Text and contrast. Headings use the dark stop, body copy uses mid, captions and metadata use the light stop for natural visual hierarchy.

#3E4E6C — Heading #6B7A9F — Body #9BA8C2 — Caption
Meridian Mint

Step 4 · Accent

Meridian Mint

Highlights, CTAs, and decorative touches. Reserved for action buttons, positive trends, success states, and key interactive elements.

#00C896 — Action #00A87E — Hover #E6FBF4 — Tint

07 · Usage rules

Do & don't

These rules protect brand consistency. They apply to every surface — marketing, product, and print.

Do

Use Trust Navy as the dominant color across all primary brand elements and navigation.

Don't

Don't substitute the primary navy with other blues or mix in off-palette colors.

Do

Reserve Meridian Mint exclusively for CTAs, positive data, and key interactive elements.

Don't

Don't use the mint accent color for backgrounds, decorative patterns, or non-interactive elements.

Do

Use DM Serif Display for all display-level headlines and major section titles.

Don't

Don't use DM Serif Display for body text, UI labels, buttons, or small copy under 18px.

Do

Maintain generous white space. Use Cloud Frost (#F0F4FB) as the page background consistently.

Don't

Don't add drop shadows, gradients, or decorative effects that aren't in this system.
